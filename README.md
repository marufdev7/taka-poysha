# 💰 টাকা-পয়সা (Taka-Poysha) — পারিবারিক ও ব্যক্তিগত আর্থিক ট্র্যাকার

**টাকা-পয়সা (Taka-Poysha)** একটি আধুনিক, ফুল-স্ট্যাক ও রিয়েল-টাইম আয়-ব্যয় এবং দেনা-পাওনা ট্র্যাকিং ওয়েব অ্যাপ্লিকেশন। এটি একই সাথে ব্যক্তিগত বাজেট নিয়ন্ত্রণ এবং যৌথ পরিবারের সদস্যদের সমন্বিত আর্থিক ব্যবস্থাপনা নিশ্চিত করার জন্য তৈরি করা হয়েছে।

---

## 🌟 প্রধান প্রধান ফিচারসমূহ (Key Features)

### ১. 👨‍👩‍👧‍👦 ডুয়াল মোড ও পারিবারিক ব্যবস্থাপনা (Dual Mode & Household)
- **ব্যক্তিগত ভিউ (Personal View):** শুধুমাত্র নিজের আয়-ব্যয় ও ওয়ালেট ব্যালেন্স পর্যবেক্ষণ করুন।
- **পারিবারিক ভিউ (Family View):** পরিবারের সকল সদস্যদের সমন্বিত হিসাব, কার কত অবদান ও খরচ তা এক নজরে দেখুন।
- **ফ্যামিলি ইনভাইট কোড (Invite Code):** ইউনিক ইনভাইট কোড ব্যবহার করে পরিবারের নতুন সদস্যদের যুক্ত করার সুবিধা।
- **মেম্বার সুইচিং:** এক ক্লিকে পরিবারের বিভিন্ন সদস্যদের প্রোফাইলে সুইচ করে লেনদেন পরিচালনা।

### ২. 💳 মাল্টি-ওয়ালেট ও অ্যাকাউন্ট ব্যবস্থাপনা (Multi-Wallet Accounts)
- ক্যাশ (Cash), বিকাশ (bKash), নগদ (Nagad), রকেট ও ব্যাংক একাউন্ট যুক্ত ও ট্র্যাক করার সুবিধা।
- প্রতিটি লেনদেনের সাথে সাথে নির্বাচিত ওয়ালেটের ব্যালেন্স রিয়েল-টাইম অটো-আপডেট।
- ওয়ালেটের ধরন অনুযায়ী ক্যাশ অ্যাকাউন্ট অগ্রাধিকার তালিকা।

### ৩. 🤝 ধার ও দেনা-পাওনা ট্র্যাকার (Debts & Loans Tracker)
- **পাওনা (Receivable) ও দেনা (Payable):** কে আপনার কাছে টাকা পাবে এবং আপনি কার কাছে কত পাবেন তা স্পষ্ট ট্র্যাকিং।
- **পরিশোধের তারিখ পরিবর্তন (Settlement Date Selection):** ধার পরিশোধের সময় কোন তারিখে টাকা পরিশোধ করা হয়েছে তা নির্দিষ্ট করে ট্রানজ্যাকশন এন্ট্রি দেওয়ার সুবিধা।
- **নির্ধারিত তারিখ পুনঃনির্ধারণ (Reschedule Due Date):** বকেয়া পরিশোধের তারিখ পেছাতে চাইলে ইনলাইন ডেট-পিকার ও কুইক চিপস (`+৩ দিন`, `+৭ দিন`, `+১৫ দিন`, `+১ মাস`) দিয়ে সহজে তারিখ আপডেট।
- **সম্পূর্ণ ও আংশিক পরিশোধ (Full & Partial Settle):** একবারে বা কিস্তিতে আংশিক টাকা পরিশোধ এবং অবশিষ্ট টাকার জন্য নতুন নির্ধারিত তারিখ সেট করার সুবিধা।
- **আজকের দেনা-পাওনা রিমাইন্ডার পপআপ (Debt Reminder Popup):** 
  - নির্ধারিত তারিখ উপস্থিত হলে বা মেয়াদোত্তীর্ণ হলে স্বয়ংক্রিয় রিমাইন্ডার।
  - পপআপের ভেতর থেকেই সরাসরি তারিখ পরিবর্তন (Reschedule) বা পরিশোধ সম্পন্ন করার অপশন।

### ৪. 📊 আধুনিক অ্যানালিটিক্স ও ইন্টারেক্টিভ চার্ট (Smart Analytics)
- **খাতভিত্তিক খরচের বিশ্লেষণ (Expense Pie Chart):**
  - ডার্ক/ব্ল্যাক ফোকাস বক্স মুক্ত স্মুথ ইন্টারঅ্যাকশন।
  - স্মুথ হোভার অ্যানিমেশন ও ফ্রস্টেড গ্লাস টুলটিপে খাতের নাম, টাকার পরিমাণ এবং মোট খরচের শতাংশ (`%`) প্রদর্শন।
- **আয় বনাম ব্যয় তুলনা (Monthly Bar Chart):**
  - প্রতিটি বারের জন্য আলাদা ও স্পষ্ট হোভার টুলটিপ (সবুজ বারে মোট আয় এবং লাল বারে মোট ব্যয়)।
  - ১২ মাসের সঠিক বাংলা নাম ও ক্রমানুসারে সাজানো চার্ট।

### ৫. 🤖 এআই আর্থিক সহকারী ও স্মার্ট রিপোর্ট (AI Assistant & Insights)
- **এআই ফাইন্যান্সিয়াল চ্যাটবট (AI Assistant):** 
  - রিয়েল-টাইম ডাটার ওপর ভিত্তি করে আর্থিক পরামর্শ ও বাজেট অ্যানালাইসিস।
  - ইসলামিক সম্মানসূচক সম্ভাষণ ও পরিষ্কার বাংলায় আর্থিক প্রশ্নের উত্তর।
- **মাসিক এআই আর্থিক রিপোর্ট (AI Report):**
  - আয়-ব্যয়ের তারতম্য, ঘাটতি বা সঞ্চয় বৃদ্ধির কারণ বিশ্লেষণ।
  - অপ্রয়োজনীয় ব্যয় কমানো ও সঞ্চয় বাড়ানোর বুদ্ধিদীপ্ত পরামর্শ।
  - এক ক্লিকে অফিশিয়াল PDF রিপোর্ট ডাউনলোড সুবিধা।

### ৬. 📅 আয়-ব্যয় ক্যালেন্ডার ও সকল খতিয়ান (Calendar & Ledger)
- ক্যালেন্ডার ভিউতে মাসের প্রতিটি দিনের মোট আয় ও ব্যয়ের রঙিন সারসংক্ষেপ।
- নির্দিষ্ট তারিখে ক্লিক করে ওই দিনের সম্পূর্ণ লেনদেনের বিবরণ দেখা।
- বিস্তারিত লেনদেন খতিয়ান, ফিল্টারিং ও সার্চ সুবিধা।

### ৭. ⚙️ সেটিংস ও বিপজ্জনক এলাকা (Settings & Danger Zone)
- **বাংলা সংখ্যা সাপোর্ট:** বাংলা (১২৩৪) বনাম ইংরেজি (1234) সংখ্যার টগল সুইচ।
- **প্রোফাইল ও সেটিংস পৃথকীকরণ:** প্রোফাইল এডিটের পাশাপাশি ডেডিকেটেড সেটিংস প্যানেল।
- **বিপজ্জনক এলাকা (Danger Zone):** অসাবধানতাবশত ডাটা মুছে যাওয়ার ঝুঁকি এড়াতে সতর্কবার্তাসহ সুরক্ষিত জোন এবং অ্যাডমিন সিকিউরিটি পিন (PIN) যাচাইকরণ দিয়ে সম্পূর্ণ ডাটা রিসেট করার নিরাপত্তা ব্যবস্থা।

## 🛠️ টেক স্ট্যাক (Tech Stack)

- **Frontend & Framework:** [Next.js 14](https://nextjs.org/) (App Router), [React 18](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), Lucide Icons
- **Data Visualization:** [Recharts](https://recharts.org/)
- **Database ORM:** [Prisma ORM](https://www.prisma.io/)
- **Database Engine:** PostgreSQL
- **AI Integration:** Google Gemini API
- **Document Export:** html2pdf.js / jsPDF

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

### ১. ক্লোন ও ডিপেন্ডেন্সি ইনস্টলেশন:
```bash
git clone https://github.com/marufdev7/taka-poysha.git
cd taka-poysha
npm install
```

### ২. এনভায়রনমেন্ট ভ্যারিয়েবল কনফিগারেশন:
`.env.example` ফাইল কপি করে `.env` তৈরি করুন এবং প্রয়োজনীয় ক্রেডেনশিয়াল প্রদান করুন:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/taka_poysha?schema=public"
GEMINI_API_KEY="your-google-gemini-api-key"
ADMIN_PIN="1234"
```

### ৩. ডাটাবেস মাইগ্রেশন ও সিড:
```bash
npm run prisma:push
npm run prisma:seed
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।
